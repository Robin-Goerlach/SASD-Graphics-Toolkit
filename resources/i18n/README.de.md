# Textkatalog-Gerüst
[English](README.md).

Die leeren UTF-8-JSON-Kataloge ordnen stabile Textschlüssel Zeichenketten zu.
Noch existiert keine Lokalisierungslaufzeit. Schlüssel mit der ersten echten Demo ergänzen.
Weitere Sprachen in [project.json](../../spec/project.json) registrieren.
Schlüsselmengen synchron halten; künftige Laufzeitregel: gewählte Sprache, danach Englisch-Fallback.
Benutzerdaten, Vertrags-IDs, API-Bezeichner und technische SVG-Zahlen nicht übersetzen.
Siehe [mehrsprachige Entwicklung](../../docs/de/050_Multilanguage_Development.md).
